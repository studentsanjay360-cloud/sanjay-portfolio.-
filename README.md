# Sanjay T — ECE Portfolio

A responsive, dark-blue portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation and footer year
- `resume.pdf` — optional: add your own PDF resume here

## Preview locally
Open `index.html` in a browser. No build step or package installation is needed.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `sanjay-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root. Optionally upload your resume as `resume.pdf`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment to finish and use the site URL shown on the Pages settings screen. For a project repository, the URL normally resembles `https://YOUR-USERNAME.github.io/sanjay-portfolio/`.

GitHub's official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Personalize before publishing
- Replace sample project descriptions with your real completed projects.
- Replace certification placeholders with certificates you have actually earned.
- Add your resume PDF as `resume.pdf` or change the link in `index.html`.
- Skill-bar widths are visual placeholders; edit them in `index.html` if you want to keep them.
- The email address and LinkedIn link are included based on the details provided.
